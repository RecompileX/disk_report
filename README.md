\# Disk Report



A simple C++ terminal utility for analyzing disk usage.



\## Features



\* Disk capacity

\* Available space

\* Directory size

\* File extension counts

\* Top 3 largest files

\* GiB, GB, and MB units

\* Interactive keyboard navigation



\## Requirements



\* C++17

\* `skcui.hpp`



\## Build



```bash

g++ -std=c++17 main.cpp -o disk\_report

```

or use the provide cmake build file.



\## Usage



Run `disk\_report`, select an option, and enter the directory you want to scan.



Use \*\*↑ / ↓\*\* to navigate and \*\*Enter\*\* to select.
